# 멍다이어리 🐶

스타듀밸리 감성의 픽셀 아트 강아지 건강 수첩이에요.
병원 갈 때마다 "이 약 뭐였지? 유통기한 지났나? 어디에 쓰는 거였지?" 물어보던 걸 한 곳에 모아둬요.

## 기능

- **생김새** – 견종 26가지 프리셋(믹스견·황구·흑구 포함) + 귀·털·코·무늬·털색을 골라 우리 강아지를 픽셀로 꾸미기
- **홈** – 강아지 프로필(나이 자동 계산, 특이사항), 할 일 게시판(다가오는 접종 · 기한 임박/지난 약 · 몸무게 잴 때), 지금 먹는 약
- **접종** – 접종/예방 기록, 다음 예정일 (+1달/+3달/+1년 버튼), 항목별 다음 일정과 D-day
- **몸무게** – 기록 + 픽셀 그래프, 직전/처음 대비 변화, 최저·최고
- **약상자** – 처방약의 용도(어디에 쓰는지), 먹이는 법, 유통기한, 개봉 후 사용기한, 보관법, 주의사항, 약 사진. 이름·증상으로 검색, 상태별 필터
- **물어보기 (AI)** – 약봉투·약병 사진을 올리면 AI가 읽고 웹 검색해서 복용법·주의사항을 정리 → 약상자에 바로 저장. 우리 강아지 정보와 약상자를 참고한 Q&A. 기본은 Google Gemini 무료 사용량, 원하면 Claude로 전환
- **가방** – 여러 마리 등록/전환, JSON 백업 받기·불러오기

## 데이터 저장 & 배포

- **Supabase 모드**: `js/config.js`에 Supabase URL과 공개 키를 넣으면 이메일로 로그인하고 계정에 저장해요. 폰·컴퓨터 어디서든 같은 기록을 볼 수 있어요.
- **로컬 모드**: `config.js`가 비어 있거나 "로그인 없이 쓰기"를 고르면 이 브라우저(localStorage)에만 저장해요.

👉 **Supabase 설정부터 GitHub Pages 배포까지 단계별 안내: [docs/SETUP.md](docs/SETUP.md)**

내 컴퓨터에서 실행하기 (빌드 과정 없음):

```sh
npx serve -l 3000 .   # 또는 python3 -m http.server 3000
```

## 구조

```
index.html
css/style.css     픽셀 UI (나무 테두리, 탭, 버튼)
js/config.js      Supabase URL / 공개 키
js/sprites.js     문자 그리드로 그린 픽셀 스프라이트 → SVG
js/looks.js       견종 프리셋 · 생김새 선택지
js/app.js         화면 · 로그인 · 기록 저장 · AI 물어보기
supabase/schema.sql  테이블 + RLS 정책 + 사진 보관함
supabase/functions/med-ai  AI 약 도우미 (Gemini 무료 / Claude)
```
